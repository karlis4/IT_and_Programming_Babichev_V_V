# Ответы на вопросы

## 1. Что покажет код?

```python
numbers = [1, 2, 3, 4, 5]
numbers[2] = 99
print(numbers)
```

**Вывод:**
```
[1, 2, 3, 99, 5]
```

---

## 2. Что покажет код?

```python
numbers = list(range(3))
print(numbers)
```

**Вывод:**
```
[0, 1, 2]
```

---

## 3. Что покажет код?

```python
numbers = [10] * 5
print(numbers)
```

**Вывод:**
```
[10, 10, 10, 10, 10]
```

## 4. Добавление 'Вэнди' в индексную позицию 0

**б) `names.append('Вэнди')`**

список пустой, поэтому append() (добавление в конец) фактически помещает элемент в позицию 0

# 5. Списковые методы (кратко)

**а) `index()`** — возвращает индекс первого вхождения элемента в список. Если элемента нет — ошибка `ValueError`.

**б) `insert()`** — вставляет элемент в список по указанному индексу, сдвигая остальные элементы вправо.

**в) `sort()`** — сортирует элементы списка (по возрастанию по умолчанию, по убыванию — с `reverse=True`). Изменяет список на месте.

**г) `reverse()`** — переворачивает список в обратном порядке. Изменяет список на месте.
