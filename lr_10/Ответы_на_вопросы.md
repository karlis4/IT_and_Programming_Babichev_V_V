# Ответы на вопросы

## 1. Что такое анонимная функция?
**Анонимная функция** — функция без имени, создаваемая в месте использования. В Python реализуется через **лямбда-выражение** (`lambda`). Обычно применяется для коротких одноразовых операций, передаваемых как аргумент другим функциям.

---

## 2. Опишите синтаксис объявления лямбда-выражения.

```python
lambda аргументы: выражение
```
- может принимать любое число аргументов (в т.ч. ни одного);
- содержит **только одно выражение**, результат которого возвращается;
- не использует `return`;
- может быть присвоена переменной, но чаще передаётся как аргумент.

```python
f = lambda x: x * 2
print(f(5))   # 10
```

---

## 3. Поясните назначение лямбда-выражений. Приведите примеры их использования.

**Назначение:** компактно задавать короткие функции без формального `def`, особенно при передаче в `map`, `filter`, `sorted`, `reduce`.

**Примеры:**
```python
# Сложение двух чисел
add = lambda a, b: a + b
print(add(2, 3))   # 5

# Возведение в квадрат через map
nums = [1, 2, 3]
print(list(map(lambda x: x**2, nums)))   # [1, 4, 9]

# Сортировка по ключу
words = ["banana", "kiwi", "apple"]
print(sorted(words, key=lambda w: len(w)))   # ['kiwi', 'apple', 'banana']
```

---

## 4. Приведите пример использования лямбда выражений для фильтрации элементов списка.

```python
nums = [1, 2, 3, 4, 5, 6, 7, 8]
even = list(filter(lambda x: x % 2 == 0, nums))
print(even)   # [2, 4, 6, 8]
```

## 5. Результат выполнения кода
```python
sx = '1.1 3.3 6.6'
x = list(map(float, sx.split()))
print(x[1])
```

**Будет напечатано:** `3.3`

## 6. Что будет напечатано в результате выполнения кода:

```python
data = [13, 1.3, 4, 'abs', 78]
filtered_data = list(filter(lambda x: type(x)==int, data))
print(filtered_data)
```

**Будет напечатано:** `[13, 4, 78]`
