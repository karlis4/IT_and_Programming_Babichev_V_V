## 6. Опишите структуру файла csv. Поясните последовательность действий при чтении файла csv.

**Структура CSV:** текстовый файл, в котором данные организованы в виде строк и столбцов. Каждая строка — запись, поля разделены разделителем (обычно запятой `,`, иногда `;` или табуляцией). Первая строка часто содержит заголовки (имена столбцов). Пример:
```
name,age,city
Иван,25,Москва
Мария,30,Питер
```

**Последовательность действий при чтении:**
1. Открыть файл (`open('file.csv', 'r', encoding='utf-8')`).
2. Создать объект `csv.reader` (или `csv.DictReader` для чтения с заголовками).
3. Пройти в цикле по строкам, извлекая значения полей.
4. При необходимости преобразовать типы (например, `int(...)`).
5. Закрыть файл (лучше — через `with open(...)`).

```python
import csv
with open('file.csv', encoding='utf-8') as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
```

## 10. Как определить, существует ли пара "ключ : значение" в словаре?

- Проверить наличие **ключа**: `if key in d:` (или `d.get(key) is not None`).
- Проверить наличие **пары**: 
```python
if key in d and d[key] == value:
```
Либо через `items()`:
```python
if (key, value) in d.items():
```

## 14. В чем разница между словарными методами pop() и popitem() применительно к словарям?

- **`pop(key[, default])`** — удаляет элемент по **указанному ключу** и возвращает его значение. Можно задать значение по умолчанию, если ключа нет.
- **`popitem()`** — удаляет и возвращает **последнюю добавленную** пару `(ключ, значение)` в виде кортежа. Ключ указывать не нужно. В Python 3.7+ работает по принципу LIFO.

---

## 15. Что возвращает метод items()?

Возвращает **представление** (`dict_items`) всех пар словаря в виде кортежей `(ключ, значение)`. Поддерживает итерацию, может быть преобразован в список:
```python
list(d.items())  # [(k1, v1), (k2, v2), ...]
```

---

## 16. Что возвращают методы keys() и values() словаря?

- **`keys()`** — возвращает представление (`dict_keys`) всех **ключей** словаря.
- **`values()`** — возвращает представление (`dict_values`) всех **значений** словаря.

Оба объекта поддерживают итерацию и могут быть преобразованы в список через `list()`.
