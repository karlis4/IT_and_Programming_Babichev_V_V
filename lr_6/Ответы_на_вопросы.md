# Ответы на вопросы

## 1. Индекс последнего символа в строке из 10 символов

Индексация начинается с `0`, поэтому последний символ имеет индекс **9** (`10 - 1 = 9`).

---

## 2. Недопустимый индекс

Возникнет ошибка **`IndexError: string index out of range`**. Например, если строка длиной 5, обращение к `строка[10]` или `строка[5]` вызовет ошибку.

---

## 3. Как найти длину строки

С помощью встроенной функции **`len()`**:
```python
length = len(mystring)
```

---

## 4. Что не так с кодом

```python
animal = 'Тигр'
animal(0) = 'Л'
```

**Ошибки:**
1. Использованы **круглые скобки** `()` вместо **квадратных** `[]` для индексации.
2. **Строки в Python неизменяемы** — нельзя изменить отдельный символ через присваивание.

Правильно было бы, например:
```python
animal = 'Л' + animal[1:]   # 'Лигр'
```

---

## 5. Что покажет код

```python
mystring = 'abcdefg'
print(mystring[2:5])
```

**Вывод:**
```
cde
```

**Пояснение:** срез `[2:5]` берёт символы с индекса 2 по индекс 4 (не включая 5): `c`, `d`, `e`.

---

## 6. (Вопрос отсутствует в задании)

```python
mystring = 'abcdefg'
print(mystring[3:])
```

**Вывод:**
```
defg
```

**Пояснение:** срез `[3:]` берёт символы начиная с индекса `3` и до конца строки: `d`, `e`, `f`, `g`.

---

## 7. Что покажет код

```python
mystring = 'abcdefg'
print(mystring[:3])
```

**Вывод:**
```
abc
```

**Пояснение:** срез `[:3]` берёт символы с начала до индекса 2 включительно: `a`, `b`, `c`.

---

## 8. Фрагмент с оператором `in`

```python
if 'd' in mystring:
    print("'d' является подстрокой")
else:
    print("'d' не является подстрокой")
```

---

## 9. Преобразование в нижний регистр

```python
little = big.lower()
```

Метод **`lower()`** возвращает копию строки в нижнем регистре.
