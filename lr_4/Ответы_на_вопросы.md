# Ответы на вопросы

**1. Назначение, сходства и различия read(), readline(), readlines()**

- `read()` — читает весь файл целиком и возвращает одну строку (весь текст).
- `readline()` — читает одну строку за вызов и возвращает её.
- `readlines()` — читает весь файл и возвращает список строк.

**Сходства:** все три читают данные из текстового файла и возвращают строковые данные (в Python — тип `str`).

**Различия:** объём и форма возвращаемых данных: `read()` — весь текст одной строкой; `readline()` — одна строка; `readlines()` — список всех строк.

---

**2. Как прочитать многострочный файл без read(), readline(), readlines()?**

Использовать файловый объект как итератор в цикле `for`:

```python
with open('file.txt') as f:
    for line in f:
        print(line)
```

---

**3. Задача закрытия файла**

Освободить системные ресурсы, связанные с файлом, и гарантировать, что все буферизованные данные записаны на диск. Также снимается блокировка файла для других процессов.

---

**4. Что такое позиция считывания файла? Где она изначально?**

Позиция считывания — это указатель (индекс) на место в файле, с которого будет прочитан следующий байт/символ. При открытии файла на чтение она изначально находится **в начале файла** (позиция 0).

---

**5. Режим для записи с сохранением содержимого**

Режим **дозаписи** — `'a'` (append). Данные записываются **в конец файла**, существующее содержимое остаётся нетронутым.

---

**6. Что такое исключение?**

Исключение — это событие, возникающее во время выполнения программы при ошибке или нештатной ситуации, которое нарушает нормальный ход выполнения и может быть обработано инструкцией `try/except`.

---

**7. Если исключение не обрабатывается try/except**

Программа аварийно завершается, выводя traceback (сообщение об ошибке с указанием места её возникновения).

---

**8. Исключение при открытии несуществующего файла**

`FileNotFoundError` (в Python 3).

---

**9. Исключение при float() для нечисловой строки**

`ValueError`.

---

**10. Файл не существует, открытие в режиме дозаписи ('a')**

Файл будет **создан** автоматически, и запись пойдёт с начала (в новый пустой файл).
