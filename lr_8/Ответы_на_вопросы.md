# Ответы на вопросы

## 1. Что такое модуль в Python?

**Модуль** — это файл с расширением `.py`, содержащий код Python (функции, классы, переменные, исполняемые инструкции). Модули позволяют:
- организовать код по логическим блокам;
- повторно использовать код в разных программах;
- избегать конфликтов имён (за счёт пространств имён).

Модуль можно **импортировать** в другую программу. Также модулем считается любой файл `.py`, доступный интерпретатору. Кроме того, существуют **пакеты** — каталоги с модулями, содержащие файл `__init__.py`.

---

## 2. Сколько модулей может подключить программист?

**Неограниченное количество.** Ограничений на число подключаемых модулей в Python нет — можно импортировать столько, сколько требуется (ограничение лишь ресурсы памяти и производительность).

---

## 3. С использованием какой команды производится подключение модуля?

Используется ключевое слово **`import`**. Варианты:
```python
import math                  # импорт всего модуля
import math as m             # импорт с псевдонимом
from math import sqrt        # импорт конкретной функции
from math import *           # импорт всех имён (не рекомендуется)
```

## 5. Перечислите несколько функций, классов модуля itertools, поясните назначение этих функций, классов.

Модуль `itertools` содержит инструменты для эффективной работы с итераторами.

**Бесконечные итераторы:**
- **`count(start, step)`** — бесконечная арифметическая последовательность.
- **`cycle(iterable)`** — бесконечное повторение элементов.
- **`repeat(obj, times)`** — повторение объекта заданное число раз.

**Итераторы, завершающиеся на shortest:**
- **`chain(*iterables)`** — последовательное объединение итераторов.
- **`zip_longest(*iterables, fillvalue)`** — как `zip`, но по самому длинному, с заполнением.
- **`islice(iterable, start, stop, step)`** — срез итератора.
- **`groupby(iterable, key)`** — группировка соседних элементов по ключу.
- **`tee(iterable, n)`** — разветвление одного итератора на n независимых.

**Комбинаторика:**
- **`product(*iterables, repeat)`** — декартово произведение.
- **`permutations(iterable, r)`** — перестановки.
- **`combinations(iterable, r)`** — сочетания без повторений.
- **`combinations_with_replacement(iterable, r)`** — сочетания с повторениями.

**Пример:**
```python
from itertools import count, combinations, product
list(combinations([1,2,3], 2))  # [(1,2), (1,3), (2,3)]
```

## 6. Укажите модули библиотеки python, которые вы уже знаете. Опишите назначение и возможности данных модулей.

- **`math`** — математические константы (pi, e) и функции: `sqrt`, `pow`, `sin`, `cos`, `log`, `factorial`, `gcd`, `ceil`, `floor`.
- **`random`** — генерация случайных чисел: `random()`, `randint()`, `choice()`, `shuffle()`, `sample()`, `uniform()`.
- **`datetime`** — классы `date`, `time`, `datetime`, `timedelta`; форматирование и арифметика дат.
- **`os`** — работа с файловой системой и ОС: `os.path`, `os.listdir()`, `os.mkdir()`, `os.environ`, `os.system()`.
- **`sys`** — доступ к параметрам интерпретатора: `sys.argv`, `sys.exit()`, `sys.stdin/stdout/stderr`, `sys.path`.
- **`json`** — сериализация/десериализация: `json.dumps()`, `json.loads()`, `json.dump()`, `json.load()`.
- **`csv`** — чтение/запись CSV: `csv.reader`, `csv.writer`, `csv.DictReader`, `csv.DictWriter`.
- **`re`** — регулярные выражения: `re.match`, `re.search`, `re.findall`, `re.sub`, `re.compile`.
- **`collections`** — `Counter`, `deque`, `defaultdict`, `OrderedDict`, `namedtuple`.
- **`itertools`** — итераторы и комбинаторика (см. п. 5).
- **`functools`** — `reduce`, `lru_cache`, `partial`, `wraps`.
- **`time`** — `time()`, `sleep()`, `strftime()`, `localtime()`.
- **`tkinter`** — создание окон, кнопок, полей ввода — графический интерфейс.
- **`sqlite3`** — встроенная база данных: `connect()`, `cursor()`, `execute()`, `fetchall()`.
- **`unittest`** — модуль для написания и запуска тестов.
- **`pickle`** — сериализация объектов Python в бинарный формат.
- **`argparse`** — разбор аргументов командной строки.
- **`logging`** — ведение журналов работы программы.
- **`threading` / `multiprocessing`** — многопоточность и многопроцессность.
