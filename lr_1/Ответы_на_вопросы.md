**1. Чем отличается интерпретируемый язык программирования от компилируемого?**
*   **Компилируемый:** Исходный код целиком переводится в машинный код (исполняемый файл) специальной программой (компилятором) до запуска. После этого программа выполняется без исходного кода.
*   **Интерпретируемый:** Исходный код построчно переводится и выполняется специальной программой (интерпретатором) непосредственно во время запуска программы.

**2. Перечислите компилируемые языки программирования.**

C, C++, Go (Golang), Rust, Pascal, Fortran.

**3. Перечислите интерпретируемые языки программирования.**
Python, JavaScript, PHP, Ruby, Perl.

**4. Как объявляются переменные в языке Python?**
Объявление не требуется. Переменная создается в момент первого присваивания ей значения. Синтаксис: `имя_переменной = значение`.

**5. Каким образом определить тип переменной в языке Python?**
С помощью встроенной функции `type()`. Пример: `type(переменная)`.

**6. Для чего используется функция print()?**
Для вывода текстовой или числовой информации в консоль (стандартный поток вывода).

**7. Какая функция предназначена для вычисления модуля в Python? Какую библиотеку необходимо для этого подключить?**
Функция `abs()`. Она является встроенной, поэтому подключать библиотеку (импортировать) не нужно.

**8. Какие из перечисленных идентификаторов нельзя использовать в качестве имен пользовательских переменных?**
`int` (ключевое слово), `create-var` (содержит дефис, который воспринимается как минус), `4perem` (начинается с цифры), `string` (ключевое слово в Python 3+, хотя и нестрогое, но крайне не рекомендуется), `System.Double` (содержит точку). Также `double_1` и `_b200` — допустимы.

**9. Перечислите основные типы в Python.**
`int` (целые числа), `float` (числа с плавающей точкой), `str` (строки), `bool` (логический тип: True/False), `list` (списки), `tuple` (кортежи), `dict` (словари), `set` (множества).

**10. Как называется программа, которая выполняет специализированную задачу, в частности, такие программы, как вирусный сканер, программа сжатия файлов или программа резервного копирования данных?**
**Утилита** (или служебная программа).

**11. К какой категории программного обеспечения принадлежат программы обработки текста, программы по работе электронными таблицами, почтовые программы, веб-браузеры и компьютерные игры?**
К **прикладному программному обеспечению** (приложениям).

**12. Какого объема памяти достаточно для хранения буквы алфавита или небольшого числа?**
**1 байт** (8 бит).

**13. В какой системе исчисления все числовые значения записываются как последовательности нулей и единиц?**
В **двоичной** системе счисления.

**14. Какова задача схемы кодирования ASCII?**
Задача ASCII — сопоставить каждому символу текста (латиница, цифры, знаки препинания, управляющие символы) уникальный числовой код в диапазоне 0–127 для представления текста в компьютере.

**15. Какая схема кодирования является достаточно широкой, чтобы включать символы многих языков мира?**
**Unicode** (в частности, его распространенная реализация UTF-8).

**16. Что означают термины «цифровые данные» и «цифровое устройство»?**
*   **Цифровые данные** — информация, представленная в дискретной форме, обычно в виде последовательности двоичных чисел (битов).
*   **Цифровое устройство** — электронное устройство, которое работает с сигналами, имеющими только два устойчивых состояния (обычно обозначаемых как 0 и 1).

**17. ЦП понимает инструкции, которые написаны только на одном языке. Как называется этот язык?**
**Машинный язык** (Машинные коды).

**18. Как называется тип памяти, в которую программа должна копироваться при каждом ее исполнении центральным процессором?**
**Оперативная память** (ОЗУ, RAM).

**19. Как называется процесс, в котором участвует ЦП, когда он исполняет инструкции в программе?**
**Цикл выполнения команды** (или **машинный цикл**), состоящий из фаз: выборка (Fetch) — декодирование (Decode) — исполнение (Execute).

**20. Что такое язык ассемблера?**
Это язык программирования низкого уровня, использующий мнемонические обозначения (символьные коды) для команд процессора, каждая из которых напрямую соответствует одной машинной инструкции. Требует трансляции в машинный код с помощью ассемблера.
