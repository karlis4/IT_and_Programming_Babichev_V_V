# Ответы на вопросы

## 1. Дайте определение понятию класс.

**Класс** — это шаблон (чертёж) для создания объектов, описывающий их структуру (атрибуты) и поведение (методы). Класс инкапсулирует данные и функции, работающие с этими данными. Экземпляры класса называются **объектами**. Класс определяет тип объекта и его свойства.

---

## 2. Продемонстрируйте использование метода __init__. Поясните назначение данного метода.

`__init__` — **конструктор класса**, специальный метод, который автоматически вызывается при создании нового экземпляра. Используется для **инициализации атрибутов** объекта.

```python
class Person:
    def __init__(self, name, age):
        self.name = name    # атрибут экземпляра
        self.age = age

p = Person("Иван", 25)
print(p.name)  # Иван
```

**Назначение:** задать начальные значения атрибутов объекта в момент его создания. Возвращать значение (`return`) из `__init__` нельзя — только `None`.

---

## 3. Поясните назначение статических методов и их отличия от методов класса.

Статический метод (@staticmethod) не получает ни self, ни cls — это обычная функция внутри класса. Метод класса (@classmethod) получает cls и имеет доступ к атрибутам класса. Статический — не имеет.

---

## 4. Для чего используется параметр self в каждом методе класса?

self — ссылка на текущий экземпляр класса; через него метод обращается к атрибутам и методам этого экземпляра.

---

## 5. Сколько методов `__init__` может быть объявлено в классе?

Только один. При объявлении нескольких останется последний.

---

## 6. Каким образом в классе Python атрибут скрывается от программного кода, находящегося за пределами класса?

В Python нет строгой приватности, но используются соглашения:
- **Одно подчёркивание** `_attr` — «защищённый» атрибут (намёк: не трогать снаружи), но доступ остаётся.
- **Два подчёркивания** `__attr` — **name mangling**: Python переименовывает атрибут в `_ClassName__attr`, что затрудняет прямой доступ извне.

---

## 7. Какова задача метода __str__( )?

`__str__()` возвращает **строковое представление** объекта, понятное человеку. Используется функциями `print()`, `str()` и форматированием. Если метод не определён, выводится служебное представление вида `<__main__.Class object at 0x...>`.

---

## 8. Каким образом происходит вызов метода __str__( )?

Вызывается **автоматически**:
- при `print(obj)`;
- при `str(obj)`;
- при форматировании `f"{obj}"` и `"{}".format(obj)`.

Можно вызвать и вручную: `obj.__str__()`.

---

## 9. Что такое атрибут экземпляра?

**Атрибут экземпляра** — переменная, принадлежащая конкретному объекту и определяемая обычно в `__init__` через `self`. У каждого экземпляра своё значение, независимое от других.

---

## 10. Метод-получатель и метод-мутатор

- **Метод-получатель (getter)** — метод, возвращающий значение атрибута, не изменяя объект. Обычно имя начинается с `get_`.
- **Метод-мутатор (setter)** — метод, изменяющий значение атрибута (состояние объекта). Обычно имя начинается с `set_`.
